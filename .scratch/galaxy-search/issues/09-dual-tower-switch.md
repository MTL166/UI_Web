# 09: 双塔上线切换 + 三路验收

**What to build:** 在真实界面里启用浏览器端双塔检索：`onnxruntime-web` 加载 int8 模型做 query 编码 + 全库余弦打分，模型缺失/失败自动回退规则路。跑三路对照（规则路 / 现成 bge 基座 / 微调双塔）× 双门槛，产出「切双塔 或 回退规则路」的验收结论并执行切换。

**Blocked by:** 04 (评测 harness), 06 (双塔微调 + ONNX int8 + 向量重算), 08 (搜索与分类浏览界面)

**Status:** ready-for-agent

- [ ] 双塔检索接入主界面：向量余弦打分 + 类型词硬过滤保持一致；模型缺失/加载失败自动回退规则路且界面无感知
