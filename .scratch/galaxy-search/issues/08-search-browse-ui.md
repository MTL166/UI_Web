# 08: 搜索与分类浏览界面

**What to build:** 登录后的主界面完整竖切：居中的自然语言搜索框 + 类型 × 风格筛选器 + 结果预览网格。输入「渐变按钮」能看到带缩略图、类型/风格标签与命中原因的卡片网格；类型词命中时结果被硬过滤到对应类型；无结果时给放宽引导与分类浏览入口。检索先接规则路（双塔就绪后由 09 无缝切换）。

**Blocked by:** 02 (构建期渲染器), 03 (规则路检索核心), 07 (前端壳 + 登录门禁)

**Status:** ready-for-agent

- [ ] 搜索框（回车/按钮提交）+ 结果网格（默认 Top-24 分页）
- [ ] 类型轴仅含 6 类 + 「更多类型即将上线」提示位；风格轴标签旁有实时组件计数；类型×风格可组合筛选
- [ ] 卡片展示 webp 缩略图、类型标签、风格标签、命中原因；预览不可用组件标注「预览不可用」但仍可点开
- [ ] 类型词命中 → 结果只含该类型；无类型词 → 全库语义结果；空结果 → 放宽提示 + 分类浏览入口（不显示空页）
- [ ] 规则路下搜索 P50 < 1.0s / P95 < 2.5s；首屏（不含模型）P50 ≤ 5s（≥10Mbps）
- [ ] 检索库与 React UI 解耦，UI 只消费 `search(query)` / `filter(type×style)` 契约
