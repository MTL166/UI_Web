# 03: 规则路检索核心

**What to build:** 一个与 React 无关的检索库：输入一句中文/英文描述，先做类型词检测（命中则硬过滤到对应 galaxy 目录），再按风格/特征打分排序；无类型词时全库打分。每条结果都带命中原因，空结果给出「放宽描述 + 分类浏览」信号。这是双塔不可用时的兜底实现，也是 MVP 先落地的检索形态。

**Blocked by:** 01 (数据抽取器与特征词典)

**Status:** ready-for-agent

- [ ] `search(query)` 命中类型词表时，结果集合被硬过滤到对应类型且不含无关类型
- [ ] 无类型词时全库 6 类打分，仍返回相关组件并带命中原因
- [ ] 每条结果带 reason（类型命中 / 风格命中 / 语义相似）
- [ ] 空结果不返回空页语义，而是触发放宽引导 + 分类浏览入口
- [ ] `filter(type × style)` 组合筛选可用，标签旁有实时组件计数
- [ ] 在小型 fixture 语料上全部断言确定性（golden 可复现），不依赖网络、不依赖模型文件
